## Question

What does the one chat page look like and do, given it is a Vue (Vite) build served by the same Node API on Render?

Decisions taken for the default (owner can change them):
- Stack: Vue 3 with Vite, built to static files that the API serves at `/`. No separate frontend host.
- Interaction: a question box, an answer that appears as it streams if the API supports it, and a sources list under each answer with links and dates.
- Confidence: show the `found`, `partial`, or `not_found` label as a visible badge, so the agent's uncertainty is visible.
- Collection status: a small panel showing the last collection run per source and the item count, read from the ingest-status endpoint.

Prototype: a rough page with one question and a sample answer, reviewed with the owner. Then decide streaming, the status panel, and the layout.

Output: the chosen layout, the streaming decision, and the owner's reaction in one line.
